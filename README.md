# Nandi Epic 2026 — Sponsorship Deck

Official interactive digital sponsorship deck for **Nandi Epic 2026**, South India's premier mass-participation endurance cycling event organized by Bangalore Bicycle Championships (BBCH) and Tour of Nilgiris (TfN) team.

## Overview
- **Event Date**: Sunday, 1 February 2026
- **Route**: 100 km Bangalore to Nandi Hills (Climb finish)
- **Format**: High-impact, mobile-responsive interactive web presentation

## Tech Stack
- Pure HTML5 / CSS3 / Vanilla JavaScript
- Self-contained asset structure (`/img`)
- Zero build step required (Static)

## Deployment
This project is configured for one-click deployment on [Vercel](https://vercel.com):
1. Import repository `LazyWiz007/NandiEpic-sponsordeck` on Vercel.
2. Framework Preset: **Other**.
3. Deploy!
